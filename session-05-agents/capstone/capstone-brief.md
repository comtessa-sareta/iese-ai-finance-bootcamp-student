# Capstone — "My AI-Native Finance Workflow" (5 minutes)

You built five artifacts in two days. The capstone is a 5-minute presentation
of ONE workflow you'd actually use in your next role — assembled from what you
built, applied to a company pair YOU chose.

## Format (5 minutes, hard stop)

1. **The job** (30s) — what finance task does your workflow do? For whom?
2. **Live or recorded run** (2 min) — show it working end to end: input →
   retrieval → analysis → validated output. Terminal + generated memo on screen.
3. **The trust story** (1.5 min) — this is where grades are won:
   - where can it be wrong? show ONE failure you caught (unverified quote,
     untraceable number, stale tag, currency trap, absurd valuation...)
   - which checks catch it (schema, evidence verification, numeric grounding,
     tests, human gate)?
   - what stays human? (the sign-off, the judgment, the accountability)
4. **One number** (30s) — tokens/cost per run, minutes saved vs. manual, or
   errors caught. Any honest number beats adjectives.
5. **Next step** (30s) — what you'd add with one more week.

## Ground rules

- Company pair: any two SEC filers (pharma, banking or tech suggested). At
  least one artifact must run on YOUR pair, not the class examples.
- Everything shown must be in your GitHub repo (committed, running).
- AI-generated content must be labeled as such in your outputs. If a number in
  your deck can't be traced to a source, remove it.
- "It didn't work and here's why" is an acceptable — often excellent — trust
  story. Fabricated success is the only failing outcome.

## Rubric (what "great" looks like)

| Dimension | Weak | Strong |
|---|---|---|
| Working artifact | Slides about code | Live run, committed repo, reproducible |
| Financial reasoning | Generic AI talk | Correct finance vocabulary, right metrics for the question |
| Trust & governance | "The AI did it" | Named failure modes + the specific checks that catch them |
| Communication | Reads the terminal | Tells the decision-maker's story in 5 minutes |

## Logistics

- Presentations run in the final 25 minutes of Session 5 — pairs present in
  breakout groups of ~6; two volunteer pairs replay to the full class.
- Submit before presenting: repo URL + your generated memo (markdown or PDF).
