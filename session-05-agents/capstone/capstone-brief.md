# Capstone — "My AI-Native Finance Workflow" (submission)

You built five artifacts in two days. The capstone is a **submission — no
presentation**: your repository URL plus a one-page memo, describing ONE
workflow you'd actually use in your next role, assembled from what you built,
applied to a company pair YOU chose.

## The submission (two items)

1. **Your repository URL** — committed, running, README included.
2. **A one-page memo** (markdown or PDF, inside the repository), five sections:
   - **The job** — what finance task does your workflow do? For whom?
   - **A real run** — input → retrieval → analysis → validated output, on your
     own company pair. Paste the key output (for example your generated memo)
     or link to it inside the repository.
   - **The trust story** — this is where grades are won:
     - where can it be wrong? ONE failure you caught (unverified quote,
       untraceable number, stale tag, currency trap, absurd valuation...)
     - which check caught it (schema, evidence verification, numeric
       grounding, tests, human gate)?
     - what stays human? (the sign-off, the judgment, the accountability)
   - **One number** — tokens/cost per run, minutes saved vs. manual, or errors
     caught. Any honest number beats adjectives.
   - **Next step** — what you'd add with one more week.

## Ground rules

- Company pair: any two SEC filers (pharma, banking or tech suggested). At
  least one artifact must run on YOUR pair, not the class examples.
- Everything referenced must be in your GitHub repo (committed, running).
- AI-generated content must be labeled as such in your outputs. If a number in
  your memo can't be traced to a source, remove it.
- "It didn't work and here's why" is an acceptable — often excellent — trust
  story. Fabricated success is the only failing outcome.

## Rubric (what "great" looks like)

| Dimension | Weak | Strong |
|---|---|---|
| Working artifact | Prose about code | A reproducible run in a committed repo |
| Financial reasoning | Generic AI talk | Correct finance vocabulary, right metrics for the question |
| Trust & governance | "The AI did it" | Named failure modes + the specific checks that catch them |
| Communication | A log dump | Tells the decision-maker's story in one page |

## Logistics

- Submit at the end of Session 5: post your repository URL in the class chat;
  the memo lives inside the repository.
