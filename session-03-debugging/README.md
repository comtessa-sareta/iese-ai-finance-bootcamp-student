## Part 1 (demo) — Fix a Broken Valuation Model

`demo/broken_dcf.py` values Meridian Semiconductor (fictional; market price
$62). It crashes, and once it runs, it is confidently wrong. The repair
protocol you'll practice:

1. **Run → read the traceback** (bottom line first, then the marked line).
   Paste it to Claude — but ask for the *diagnosis* before the fix.
2. **Run the sanity tests:** `python -m pytest session-03-debugging/demo/ -q`
   Each failing test names a violated piece of financial logic.
3. **Fix bug by bug** in `broken_dcf.py` until green. The docstrings are the
   spec; the tests are the referee.
4. **Smell-test the result.** Before the fixes, the model says a $62 stock is
   worth $100+. Green tests AND a plausible number — you need both.

The most important test is `test_matches_hand_calculation`: a case simple
enough to verify by hand. If your model can't reproduce a hand-checkable case, you
don't have a model — you have a rumour.

## Part 2 (lab, 30 min) — Earnings Analysis Engine

From `data/transcript_meridian_q2_fy2026.txt` (a synthetic call — fictional
company, so the model can't lean on memorized knowledge) to a structured
investment note. Open `lab/earnings_starter.py`; it runs immediately:

```bash
python session-03-debugging/lab/earnings_starter.py --dry-run
```

Three TODOs, in order of importance:

1. **Grounding rules** (system prompt): only the transcript; verbatim quotes;
   machine-checked; unsupported → don't claim it.
2. **`verify_evidence()`** — the trust layer: check every quote against the
   source text in plain Python. The dry-run analysis contains one deliberately
   fabricated quote; when your code works, your memo flags it ⚠️ UNVERIFIED.
3. **Finish the memo renderer** (risks table, red flags, Q&A quality).

Then run live (needs `ANTHROPIC_API_KEY` in `.env`) and read YOUR memo:
did the model find the recurring "one-time" costs? The CEO/CFO margin gap?
The guidance exclusion? The DSO drift? (All four are in the transcript.)

### Want a real document instead?

Real transcripts are copyrighted, so this repo ships a synthetic one. Earnings
*press releases*, however, are filed publicly as 8-K exhibits — in Session 4
you'll fetch them straight from EDGAR (`toolkit.edgar.fetch_filing_text`) and
can point your engine at the real thing.
